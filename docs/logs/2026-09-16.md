## 트러블슈팅

### 1. `pytest` 실행 시 `ModuleNotFoundError: No module named 'converse'`
- **원인**: `converse.py`가 `src/zipsai/` 밖(repo root)에 있었음. `pytest`는 스크립트 직접 실행과 달리 실행 위치(root)를 `sys.path`에 자동으로 넣어주지 않음 — 테스트 파일 기준 디렉터리만 잡음.
- **해결**: `converse.py`를 `src/zipsai/contracts/converse.py`로, 테스트를 `tests/unit/test_converse.py`로 이동. `uv` 패키지 프로젝트라 `zipsai` 패키지가 정상 임포트되며 해결.

### 2. Cerebras 전환 시 "API 키만 바꾸면 된다"는 착각
- **원인**: OpenAI SDK 호환이라 코드 구조는 같지만, `base_url`(`https://api.cerebras.ai/v1`)과 모델 ID가 OpenRouter/OpenAI와 다름. `gpt-5-nano`는 Cerebras에 없음.
- **해결**: `api_key`/`base_url`/`model`을 전부 환경변수로 분리(`.env`)해서 provider 전환 시 코드 수정 없이 값만 바꾸도록 정리. Vision 테스트는 Cerebras의 vision 지원 모델(`llama3.2-11b-vision`)/Qwen으로 사용.

### 3. `Literal` 사용이 팀 컨벤션 위반이었음을 뒤늦게 발견
- **원인**: `docs/CONVENTIONS.md`에 "`route`/`state`/`intent` 고정값은 Enum으로 관리한다"는 규칙이 이미 있었는데, `converse.py` 초안 작성 시 이를 놓치고 `Literal`로 정의함.
- **해결**: 다음 작업(커밋 2, `converse` 라우팅 계약 정의)에서 `Route`/`ConversationState`/`IssueType` 등을 Enum으로 전면 교체하기로 확정.
