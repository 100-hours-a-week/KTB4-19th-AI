# zipsAI 합성데이터

건물관리 문서 RAG의 인덱싱·검색을 검증하기 위한 합성 데이터셋이다.
순천향대 인근 4구역의 원룸형 빌라·다가구주택 10개동을 대상으로 만들었다.

문서만 만드는 것이 아니라 **정답셋을 함께** 들고 있다.
정답셋이 없으면 검색 품질이 좋아졌는지 나빠졌는지 잴 수가 없다.

## 두 부분으로 나뉜다

| 폴더 | 무엇 | 누가 보나 |
|---|---|---|
| [`1-dataset/`](1-dataset/) | **완성물.** 파싱 단계에 바로 넣는 파일과 안내 문서 | 데이터를 쓰는 사람 |
| [`2-reproduce/`](2-reproduce/) | **재현 방법.** 원본 md, 생성 스크립트, 스키마 정의 | 데이터를 고치거나 늘리는 사람 |

`1-dataset/`은 `2-reproduce/`에서 만들어진 파생물이다. 문서를 고칠 때는 `2-reproduce/`의
원본 md를 고치고 스크립트를 다시 돌린다. `1-dataset/`을 직접 손대지 않는다.

## 1-dataset — 완성물

| 항목 | 내용 |
|---|---|
| `데이터셋-안내.md` | 건물 10개 구성, 답있음/답없음 주제, 문서 종류 — 표 3개 |
| `build/` | 파싱 입력 51건 — 본문 PDF 46, 스캔본 PDF 3, 사진공지 jpg 2 |

## 2-reproduce — 재현 방법

```bash
cd 2-reproduce
python3 validate.py       # 데이터셋 제약 검사
python3 make_inputs.py    # 1-dataset/build/ 생성
python3 make_report.py    # 1-dataset/데이터셋-안내.md 갱신
```

자세한 내용은 [`2-reproduce/README.md`](2-reproduce/README.md).

## 규모

| 항목 | 값 |
|---|---|
| 건물 / 호실 / 구역 | 10 / 300 / 4 |
| 원본 문서 | 51건 |
| 정답셋 | 235문항 (답있음 135 / 답없음 100) |
| 경로 B 카드 | 50건 (답없음 100 중 관리자가 답한 것) |

## 알아둘 것

**가짜 개인정보가 일부러 들어 있다.** 마스킹 단계를 시험하려고 심은 것이며
휴대전화·차량번호·「302호 김미정님」류 표현 모두 실존하지 않는 합성값이다.

**실존 건물명·주소를 쓰지 않았다.** 건물명은 전부 지어낸 이름이다.
